# Predictive Climate Modeling Using AI – CO₂ Emissions Forecasting

A simple college-level machine learning web app built with Python and Streamlit.

## Features
- Included demo India dataset (1990–2024)
- CO₂ trend and EDA charts
- Linear Regression and Random Forest
- MAE, RMSE and R² evaluation
- Interactive CO₂ prediction form

## Run in VS Code

```bash
git clone https://github.com/Akashpawar-sky/PredictiveCimate.git
cd PredictiveCimate
python -m venv .venv
```

Windows PowerShell:
```powershell
.venv\\Scripts\\activate
```

Install:
```bash
pip install -r requirements.txt
```

Run:
```bash
streamlit run app.py
```

## Important dataset note
The included CSV is an illustrative demo dataset so a beginner can clone and run the project immediately. Replace it with a verified OWID-derived dataset before using numerical results in the dissertation.
